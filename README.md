# JAX-CO — SD Universe Project

[![Docs](https://img.shields.io/badge/docs-ready-blue)](docs/project_overview.md) [![Build](https://img.shields.io/badge/build-pending-lightgrey)]() [![License](https://img.shields.io/badge/license-Proprietary-red)]()

Short description: A modular platform combining a tiny trusted foundation, secure module runtime, and a conversational assistant for safe device automation and local personalization.

## 2-minute demo

Clone the repo and open the docs branch:

```bash
git clone https://github.com/hey-sd/jax-co.git
cd jax-co
git checkout docs/init-docs
# View the quickstart
less docs/quickstart.md
```

## Quickstart (TL;DR)

1. Ensure prerequisites: git, docker (optional), python3 (for demo tools)
2. Checkout docs branch: `git checkout docs/init-docs`
3. View the project overview: `less docs/project_overview.md`
4. Run the local docs staging script (no effect if already present): `./tools/stage_docs_for_commit.sh`
